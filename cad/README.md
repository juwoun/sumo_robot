# CAD (SolidWorks)

- `solidworks/` : SolidWorks 원본 파일 (부품 .SLDPRT, 조립 .SLDASM) — 조립 파일은 부품 파일과 같은 폴더에 있어야 열려요
- `stl/` : 3D 프린팅용 STL — GitHub에서 클릭하면 3D로 돌려 볼 수 있어요

| 파일 | 설명 |
|---|---|
| 어셈블리1.SLDASM | 로봇 전체 조립 |

| f2 | f1과 연결되는 부분 — 모터·바퀴 장착 |
| f3_raspi / f4_raspi | 라즈베리 파이 장착 부품 |

| F7_cap | 덮개 |
| 바퀴 | 바퀴 (지름 100mm, 폭 40mm) — 시뮬레이션용 `좌표계1`(바퀴 정중앙, Y = 바퀴 축) 포함 |
| 카메라 거치대 | Pixy2 카메라 거치대 |
